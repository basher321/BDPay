## 4. Unclear or possibly wrong in the spec

Decision needed before execution
- D1. **Where the text goes.** CLAUDE.md says all user-facing text comes from ARB l10n files, but ARB needs the
  Flutter SDK package flutter_localizations, which the spec doesn't name ("Add no package that the
  current spec does not name"). Either way breaks one rule, so please choose:
  A. ARB + gen-l10n, adding flutter_localizations (SDK, nothing downloaded). Follows CLAUDE.md.
  B. lib/core/strings_bn.dart constants, no extra package. Follows the spec's package list; moving to ARB later
     is mechanical.
  Recommendation: A.

Other points
1. **The reference file is missing.** The spec copies tokens from reference/bdpay-sms-verifier-v2.html,
   which does not exist. Only "BDPay SMS Verifier.html" is in the root, and its t2/t3 (#94A3B8/#64748B)
   differ from the spec (#B4C0D3/#8A9AB3). Plan: use the spec's hex values; add the v2 file so the raw
   SMS texts and the look can be checked against it.
2. **The fonts are missing.** app/assets/fonts doesn't exist yet. Execution stops at command 4 until you add them.
3. **Folder.** The spec uses app/, CLAUDE.md says apps/mobile. The spec wins (CLAUDE.md: "the current step spec
   wins"). Suggest updating CLAUDE.md.
4. **No expired status.** VerifyStatus has no `expired`, but CLAUDE.md's claim status list has it. The spec wins for now,
   but once the server sends "expired", fromWire will throw. Add it in a later spec or now?
5. **Enum naming.** CLAUDE.md says "device queue status"; the spec calls it SyncStatus with the same values. No conflict.
6. **Which retry is mocked.** "MOCK - replaced by the server in spec 13". In the roadmap the app is wired to the server
   in step 18. The comment is written exactly as specified.
7. **Retry scope (assumption, not stated in the spec).** retry() on an item already sent does nothing.
   retryAllPending() covers queued + failed only. The simulated result changes verifyStatus only when it is pending.
8. **Digits.** timeAgo uses Latin digits ("5 মিনিট আগে"), as the reference does.
9. **No dev-mode switch yet.** Developer mode can only be changed through SettingsRepository in this spec; the switch
   comes with the Settings spec.
10. **Subtitle.** "পেমেন্ট যাচাই অ্যাপ" replaces the reference's "MFS Gateway Receiver"; the spec wins.
11. **Product spec missing.** CLAUDE.md points to docs/specs/001-product-spec.md, but docs/ is no longer in the project.
